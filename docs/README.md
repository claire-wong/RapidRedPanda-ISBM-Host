# Documentation

RapidRedPanda ISBM Host exposes OpenO&M ISBM 2.0 REST messaging services using .NET 10, SQL Server, and Azure Service Bus. ISA-95 Part 6 supplies the standards context; participation in an OpenO&M project is not required.

These pages describe source-reviewed behavior, not full conformance or production readiness. Installation, messaging, callbacks, and deployment still require authorized runtime validation.
